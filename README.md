# 🌐 ConnectHub

- A powerful all-in-one Discord community bot designed to manage, protect, and grow servers
- ConnectHub provides automation, moderation, and community engagement tools in one place

## ✨ Core Features

### 🛡️ Moderation System

- Comprehensive moderation tools (ban, kick, mute, warn, clear)
- Role-based permission control for safe command usage
- Nickname management and user moderation
- Designed to simplify and speed up server moderation

### 📝 Logging System

-   Tracks important server events:
    - **Member joins**
    - **Message creations, edits, deletions**
    - **Reactions**
    - **And much more**
-   Configurable logging channels
-   Helps maintain transparency and moderation history

### 🤖 Automation & Utility

-   Custom embed and message sending
-   Voting and quick poll systems
-   Role management and reaction roles
-   Server information and utility tools

### 🎉 Giveaway System

-   Create and manage giveaways
-   Store and manage giveaway channels
-   Reward roles for winners

### 🧹 Anti-Spam & Filters

-   Built-in spam detection system
-   Automatic bad word filtering using custom word lists
-   Message cleanup and protection

### 🚨 Anti-Raid Protection

-   Detects and prevents raid-like behavior
-   Protects servers from mass joins or spam attacks

### 👋 Community Features

-   Welcome messages for new members
-   Partner system for server collaborations
-   Basic help system for users and admins

## 🧰 Built With

- Programming language: **JavaScript *(Node.js - latest version)***
- Discord library: **discord.js *(minimum v14)***
    - Install with: ``npm install discord.js``
- Package manager: **npm *(latest version)***
    - Initialize with: ``npm init -y``

## ⚠️ Notes

-   Prefix: `.`
-   The bot requires a role with proper permissions
